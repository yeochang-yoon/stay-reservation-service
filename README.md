# Stay Reservation Service

현재 애플리케이션과 Build 설정은 아직 없습니다. Backend 기반 구축 단계에서 실제 검증한 실행·Build·Test 명령을 추가합니다.

개발 흐름은 [개발 절차](docs/DEVELOPMENT_PROCESS.md), Codex의 실행·검수·Git 승인과 세션 운영은 [작업 원칙](AGENTS.md)을 따릅니다.
